## How to Run Locally

1. **Clone or download** this repository to your machine.
2. Navigate into the root folder `vcs_school/`.
3. Open **`index.html`** from GitHub file in any modern web browser (Chrome, Firefox, Edge, Safari) to launch the landing page.
4. Use the navigation links on the main page to click through and explore the nested folders like `forms` and `Activity_9_Student_Info`.
